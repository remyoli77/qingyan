# 国风 AI Agent 应用界面 - 产品需求文档

## 1. 产品概述

本项目是一款融合中国传统美学与现代 AI Agent 交互理念的应用界面，以「青绿山水 + 宋代文人审美」为视觉基调，将 AI 自主任务规划、对话、工具调用等能力，以卷轴、信笺、行军图、多宝阁等国风意象进行可视化呈现。

- **目标用户**：喜爱传统文化、追求审美品质的内容创作者、文化研究者、设计与文案从业者
- **核心价值**：在 AI 工具同质化严重的当下，以独特国风美学建立差异化的交互体验，让 Agent 的"思考过程"本身成为一种可观赏的视觉叙事

## 2. 核心功能

### 2.1 功能模块

| 模块 | 说明 |
|------|------|
| 首页 / 主界面 | 水墨长卷动态背景、品牌书法标题、卷轴式 AI 对话入口、多宝阁功能宫格 |
| 对话界面 | 信笺式对话气泡、毛笔书写动效、朱印引用批注、古风 Agent 头像 |
| Agent 任务规划 | 行军图 / 游记路线图式任务展开、工具调用研墨铺纸动效、手札记忆面板 |

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 顶部山水长卷 | 青绿山水渐层动态背景，墨色品牌名（书法体）+ 诗词 slogan |
| 首页 | 中央对话入口 | 卷轴造型输入框，展开动效；下方提示词以竹简样式排列 |
| 首页 | 多宝阁功能宫格 | 诗词、书画、茶道、节气、古琴、问道 六个功能卡片，每卡含小幅画作 + 印章式标签 |
| 对话界面 | 信笺对话流 | AI/用户消息以信笺/竹简造型呈现，墨迹晕染逐字显现 |
| 对话界面 | 朱印批注引用 | 引用来源以朱色圈点 + 侧边小字呈现，仿古籍批注 |
| 对话界面 | 工具调用浮窗 | Agent 调用工具时显示「研墨」「铺纸」「翻书」动效隐喻 |
| 任务规划 | 行军图长卷 | 任务步骤以山水长卷形式展开，节点为亭台楼阁图标 |
| 任务规划 | 手札记忆 | 侧边面板展示 Agent 记住的上下文，仿线装手札样式 |

## 3. 核心流程

用户从首页卷轴入口发起对话 → Agent 接收请求并展开任务规划长卷 → 逐步执行（工具调用动效）→ 结果以信笺形式呈现并附带朱印引用 → 用户可查看手札记忆面板回顾上下文。

## 4. 用户界面设计

### 4.1 设计风格

**视觉基调：青绿山水 + 宋代文人审美**

避开俗套的大红大绿与金碧辉煌，以王希孟《千里江山图》的矿物色为灵感，结合宣纸质感与水墨晕染，追求克制、内敛、书卷气的雅致。

**配色方案（自主配色，非照抄建议）：**

| 角色 | 色名 | 色值 | 用途 |
|------|------|------|------|
| 主色 | 青碧 | `#3D6B6E` | 主交互色、强调元素，仿青绿山水的石青石绿交融 |
| 深色 | 黛青 | `#1A2E30` | 文字主色、深色背景，墨色沉静 |
| 纸色 | 宣纸 | `#F2EBDC` | 主背景，温润的米黄宣纸底 |
| 辅纸 | 蝉翼 | `#E8DFC9` | 卡片底、次级背景，略深的绢本色 |
| 点缀 | 赭石 | `#B8763E` | 次级强调，仿土红矿物色，用于图标、装饰线 |
| 朱印 | 朱砂 | `#A4392F` | 仅用于印章、引用批注圈点，克制使用 |
| 洒金 | 鎏金 | `#C9A961` | 极少量点缀，分割线、印章边框 |

**字体方案：**
- 标题：`Ma Shan Zheng`（书法体，仅用于品牌名、章节大标题）
- 副标题/装饰：`Noto Serif SC`（思源宋体，用于诗词 slogan、卡片标题）
- 正文：`Noto Sans SC`（思源黑体，保证可读性）

**布局：**
- 桌面优先，宽屏 1280px 基准，最大 1440px 居中
- 首页采用上中下三段式：山水长卷顶 → 卷轴对话中 → 多宝阁底
- 对话页采用左右双栏：左侧长卷任务规划 + 右侧信笺对话流
- 多用留白与不对称构图，避免密集卡片堆砌

**装饰元素：**
- 印章（朱砂红方形/圆形篆体印）
- 卷轴轴头（赭石色木质纹理）
- 山水轮廓线（青碧色细线 SVG）
- 宣纸纹理（CSS 噪点叠加）
- 落款（鎏金色细线小字）

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 首页 | 山水长卷顶栏 | 青绿渐层背景 + SVG 远山轮廓 + 书法体品牌名 + 宋体 slogan |
| 首页 | 卷轴对话入口 | 双轴头横向卷轴造型输入框，聚焦时卷轴微微展开，placeholder 以宋体竖排 |
| 首页 | 多宝阁宫格 | 3×2 网格，每格含小幅 SVG 画作（梅兰竹菊等）+ 朱印标签 + 悬浮抬升动效 |
| 对话页 | 左侧行军图 | 山水长卷纵向展开，任务节点为亭台 SVG，连线为虚线山径 |
| 对话页 | 右侧信笺流 | 用户消息为右浮竹简，AI 消息为左浮信笺带印章落款 |
| 对话页 | 工具调用气泡 | 内嵌研墨/铺纸 SVG 动画，配宋体小字说明 |
| 对话页 | 朱印引用 | 引用文本左侧加朱砂方框 + 圈点，仿古籍批注 |

### 4.3 响应式

- 桌面优先设计（≥1280px 完整双栏布局）
- 平板（768-1279px）：对话页右侧信笺流为主，左侧任务规划折叠为顶部展开式
- 移动端（<768px）：单栏纵向滚动，多宝阁改为横向滑动卡片

### 4.4 动效原则

- **首次入场**：山水长卷从右向左缓缓展开（卷轴展开动效），品牌名墨迹晕染显现
- **消息发送**：信笺从底部托起，伴随轻微墨迹晕染
- **工具调用**：研墨圆圈循环转动 + 铺纸横向展开，克制循环不重复播放
- **任务节点**：行军图节点依次亮起，连线如墨迹流淌
- **悬停反馈**：多宝阁卡片轻微抬升 + 朱印呼吸光晕
- **关键原则**：动效服务于叙事，关键节点触发，不每次交互都播

## 5. 技术约束

- 纯前端实现，无后端依赖，AI 响应使用本地 mock 数据模拟
- 桌面浏览器优先，需兼容 Chrome / Edge / Safari 最新版
- 单页应用，路由切换首页 / 对话页
- 装饰 SVG 内联，避免外部图片依赖（除文生图接口外不引入图片资源）
